# Street Racer: Open World (Godot 4.3)

Открытый город с солнцем, дневным светом и белой/синей M3 GTR.
Гонки не показаны на карте — их нужно находить (золотые кольца со световым столбом).

Управление: экранные кнопки (мультитач) или WASD/стрелки, Space — дрифт, Shift — нитро.
Сборка APK: push в GitHub -> Actions -> Build Android APK -> Artifacts / Releases.
